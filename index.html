What this run is doing

Each project is the upstream C++ sources, parsed and interpreted in the browser. Pac-Man Clock publishes a frame at SwapOnVSync. Pong Clock draws on the matrix itself and publishes a frame at usleep. GPIO, the Adafruit HAT, and syslog are host stubs.

Driver brightness is whatever the program sets. Pac-Man Clock uses 50. Pong Clock leaves it at 100. The preview shows the raw SetPixel colours.
