What this run is doing

Each project is the upstream C++ sources, parsed and interpreted in the browser. Pac-Man Clock publishes a frame at SwapOnVSync. Pong Clock, Matrix Clock, Tetris Clock, and Plasma Clock draw on the matrix itself and publish a frame at usleep. GPIO, the Adafruit HAT, and syslog are host stubs.

Driver brightness is whatever the program sets. Pac-Man Clock uses 50. Pong Clock, Matrix Clock, Tetris Clock, and Plasma Clock leave it at 100. The preview shows the raw SetPixel colours.

Open a project directly with ?project=pacmanclock, pongclock, matrixclock, tetrisclock, or plasmaclock.
